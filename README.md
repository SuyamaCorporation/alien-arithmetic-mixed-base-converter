# 異星人算術混合進数コンバーター＆暗算ゲーム

「銀河貿易連盟」ストーリーをテーマに進数変換を楽しく学ぶアプリです。変換ツールモードでは2/8/10/16進数の相互変換と10進数を経由した変換手順をビジュアルで解説します。ASCII変換モードでは文字を10進・16進・2進のASCIIコード表で確認できます。ゲームモードでは30秒タイムアタック形式で進数変換問題をスコア・ストリーク付きで挑戦でき、成績はlocalStorageに保存されます。難易度は3段階（イージー/ノーマル/ハード）から選択可能です。

## 使い方

タブを切り替えて各モードを使用します。変換ツールは数値と進数を選んで「変換」、ゲームモードは難易度を選んで「ゲーム開始」を押し、30秒以内に変換結果を入力してEnterキーで送信します。
